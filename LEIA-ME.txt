ANIMAIS 8º ANO - COMO INSTALAR COMO APLICATIVO (tela cheia, funciona sem internet)

O QUE TEM NESTA PASTA
  index.html                 o aplicativo (telas)
  style.css                  visual (cores, tamanhos)
  dados.js                   conteúdo: grupos, perguntas, fauna, doenças e atividades
  app.js                     funcionamento do app
  progresso.js, extras.js    progresso do aluno, naturalistas, ciclos e curiosidades
  util.js                    funções comuns
  banco-proprio.js           perguntas do professor (gerado pelo editor)
  editor.html, editor.js, editor.css   editor de questões para o professor
  tema-claro.css             cores do tema claro
  animais-8ano.html          o app inteiro em um só arquivo (gerado sozinho pelo GitHub)
  manifest.webmanifest       dados do app (nome, ícone, abre em tela cheia)
  sw.js                      guarda o app no aparelho para abrir sem internet
  icon-192.png, icon-512.png, icon-maskable-512.png   ícones
  validar-banco.js, testes/, build/, .github/   conferências automáticas (veja o README.md)

IMPORTANTE
  - O arquivo único "animais-8ano.html" funciona direto no navegador, mas NÃO consegue se
    instalar sozinho. Navegadores só instalam apps vindos de um endereço https.
  - Para o aviso "Instalar na tela inicial" funcionar de verdade, publique ESTA PASTA inteira
    (todos os arquivos juntos) em uma hospedagem de sites estáticos e use o link no celular.
    Depois da primeira abertura com internet, o app passa a abrir sem internet.

COMO PUBLICAR (exemplos gratuitos, escolha um)
  A) Netlify Drop: acesse app.netlify.com/drop e arraste a pasta. Ele gera um link https.
  B) GitHub Pages: crie um repositório, envie todos os arquivos e ative Pages nas configurações.

COMO INSTALAR NO CELULAR (depois de publicado)
  Android (Chrome): abra o link. Aparece o aviso "Instalar na tela inicial" > toque em Instalar.
    Se não aparecer: menu ⋮ > Instalar app (ou Adicionar à tela inicial).
  iPhone/iPad (Safari): abra o link > Compartilhar > Adicionar à Tela de Início.
  Computador (Chrome/Edge): ícone de instalar na barra de endereço.
  O app instalado abre em tela cheia, sem barra do navegador.

SE NÃO FOR PUBLICAR
  Abra o arquivo "animais-8ano.html" no Chrome. Em Opções, a "Tela cheia automática"
  coloca o app em tela cheia no primeiro toque.

PERFIS DOS ALUNOS
  As estrelas, o XP, o nível e o progresso das trilhas ficam salvos por aluno, somente no
  aparelho e no navegador usados. Para levar a outro aparelho, use o código em 📊 Progresso.
  Trocar de celular, de navegador ou limpar os dados do navegador apaga o progresso,
  a não ser que ele seja levado antes com o código de 📊 Progresso.

ATENÇÃO
  Os arquivos podem ser editados livremente (não há trava contra alteração).
  A versão do sw.js muda sozinha: a cada envio ao GitHub (branch main), o próprio GitHub
  recalcula a versão e gera de novo o animais-8ano.html. Assim, quem já instalou o app recebe
  a versão nova na próxima vez que abrir com internet.
